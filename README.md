# Math by UKG Lab

CBSE Mathematics learning platform for Classes 9, 10, 11 and 12.

Production domain:

```txt
https://math.ukglab.com
```

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Scope

This repository contains the initial production skeleton for Math by UKG Lab:

- Homepage and class selector
- Class 9, 10, 11 and 12 dashboards
- Chapter, lesson, practice and test routes
- Formula library, search, bookmarks and dashboard architecture
- KaTeX math rendering
- SVG diagram architecture
- SEO, sitemap, robots and GitHub Pages CNAME for `math.ukglab.com`

The sample educational content is intentionally small and original. More lessons,
questions, tests and revision material can be added through the structured
content model in `src/math/content.ts`.
